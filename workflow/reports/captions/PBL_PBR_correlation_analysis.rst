PBL-PBR correlation
====================

Each page compares PBL (left piggyBac junction) and PBR (right junction) read
counts for the same insertion sites, on a log-log scale. A tight diagonal
scatter indicates the two junction reads agree on abundance, which is the
expected pattern for a genuine insertion; points far off the diagonal are
worth a closer look.

Point colour encodes local 2D point density, rescaled independently within
each panel: the colours mark where the bulk of insertions sit, and are not
comparable between panels.
